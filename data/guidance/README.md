# Filing evidence and review files

[claims.json](claims.json) groups passages and preserves each source accession, filing date, document URL and quote. [approved.csv](approved.csv) contains one row per approval. [audit.json](audit.json) stores current decisions and changes. Each source trace records the proposals and checks. Model calls have matching [cassettes](cassettes/).

**Review in the browser.** Open [pending.csv](pending.csv), choose the pencil and enter `approve` or `reject` in `decision`. Commit on main. On a protected branch, commit on a new branch and merge the pull request. An approval rechecks the original SEC text. Use the optional edit columns for a corrected proposal. The [model-assisted subset](model_assisted.csv) provides suggestions keyed to the same IDs. [The review issue](https://github.com/davidgold00/capex-tracker-ai/issues?q=is%3Aissue+%22Guidance+claims+awaiting+review%22) links to the queue.

**Frozen audit.** Edit only `david_verdict` and `david_note` in [audit_sample.csv](audit_sample.csv). Decide whether the evidence supports the recorded decision. The values are `correct`, `incorrect` and `unsure`. A blank means unread. A sampled pending row can correctly remain pending because of unresolved evidence. The README reports agreement by policy group.
